# Gitópolis 1.0 — A Cidade do Versionamento

Jogo didático em HTML, CSS e JavaScript voltado à introdução ao Git e ao GitHub.

## Como abrir

1. Extraia o ZIP em uma pasta do computador.
2. Abra `index.html` em um navegador atualizado (Chrome, Edge ou Firefox).
3. Clique em **Explorar a cidade**, escolha o bairro desbloqueado e resolva as missões.
4. Digite os comandos no terminal simulado. Depois de acertar, o jogo exibe a explicação e retorna automaticamente à cidade em 4,5 segundos.
5. Ao final, acesse **Meu desempenho**, informe o nome (opcional) e faça o download do relatório `.html`. Abra esse relatório no navegador e use **Imprimir ou salvar em PDF** para entregar ao professor.

Nenhuma instalação, cadastro ou conexão com a internet é necessária. O jogo roda inteiramente no navegador e salva o progresso apenas no armazenamento local do dispositivo.

## Estrutura de aprendizagem

- **Bairro 1 — Praça dos Primeiros Commits:** instalação, nome e e-mail de autoria, inicialização de repositório.
- **Bairro 2 — Oficina das Alterações:** status, diff, staging, commit e log.
- **Bairro 3 — Jardim dos Branches:** criação e troca de branch, trabalho isolado e merge.
- **Bairro 4 — Porto do GitHub:** remotos, push, fetch e pull.
- **Bairro 5 — Centro Colaborativo:** clone, branch de contribuição, commit, push e pull request.

São **20 missões**, com pontos, dicas opcionais, correção de tentativas e cinco conquistas.

## O que este jogo não faz

- O terminal é uma **simulação**. Ele não executa Git real e não altera arquivos do computador.
- As URLs do GitHub usadas nas missões são **fictícias e ilustrativas**; não é necessário acessá-las.
- Os resultados do terminal representam situações didáticas, não saídas garantidas de um repositório real.
- Não existe servidor de coleta automática dos resultados: cada estudante deve entregar seu próprio arquivo de relatório.

## Como publicar na internet

Para GitHub Pages, Vercel ou outra hospedagem estática, publique `index.html` na raiz do site. Não é necessário backend ou pacote de dependências.
